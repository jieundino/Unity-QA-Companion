# Unity QA Companion

**Unity 게임 QA를 위한 테스트 케이스 관리 및 테스트 결과 기록 웹 앱**

Unity 게임 개발 과정에서 발생한 이슈를 바탕으로 테스트 케이스를 관리하고, 수동 테스트 결과와 버그 리포트를 기록할 수 있는 웹 애플리케이션입니다.

기존 `Issues.md` 파일을 활용해 이슈 관리부터 테스트 케이스 작성, 테스트 실행 결과 기록, 버그 리포트 작성까지 이어지는 QA 워크플로를 하나의 도구에서 관리하는 것을 목표로 합니다.

> ### 🚀 바로 실행해 보기 (데모 데이터 기본 탑재)
> - **웹 브라우저에서 바로 열기 (Live Preview):** [**Unity QA Companion 바로가기 (Vercel)**](https://unity-qa-companion.vercel.app/)
> - **저장소 내 단독 실행 파일:** [`UnityQACompanion-standalone.html`](./UnityQACompanion-standalone.html)
> - 별도의 JSON 백업 파일을 다운로드·로드하지 않아도 `test/` 폴더의 샘플 프로젝트(**Four Footsteps**) 데이터가 기본 탑재되어 있어 열자마자 전체 기능을 바로 테스트해 볼 수 있습니다.

## 프로젝트 소개

Unity 게임 개발 과정에서 기록한 이슈는 문제를 추적하는 데 유용하지만, 이를 체계적인 테스트 케이스로 전환하고 실제 빌드에서 검증한 결과까지 관리하려면 별도의 작업이 필요합니다.

Unity QA Companion은 이러한 작업을 간소화하기 위해 개발한 개인 프로젝트입니다.

기존 Markdown 이슈 문서를 가져와 테스트 케이스 작성에 활용하고, 외부 AI 도구를 통해 생성한 테스트 케이스를 등록할 수 있습니다. 이후 Windows 게임 빌드에서 직접 수행한 테스트 결과를 기록하고, 실패한 테스트를 바탕으로 버그 리포트와 수정 요청 메일 초안을 작성할 수 있습니다.

## 주요 기능

### 1. 프로젝트 및 이슈 관리
- 프로젝트 정보 등록 및 관리
- `Issues.md` 파일 업로드 및 Markdown 파싱
- 파싱된 이슈 목록과 상세 내용 확인
- 이슈 검색, 수정 및 관리
- 프로젝트와 이슈 데이터 연결

### 2. AI 기반 테스트 케이스 작성 지원
- 선택한 이슈를 기반으로 테스트 케이스 생성용 프롬프트 작성
- 생성된 프롬프트 복사
- 외부 AI 도구에서 생성한 결과 붙여넣기
- 테스트 케이스 데이터 검수 및 등록
- 테스트 케이스 추가, 수정, 삭제 및 검색

AI API를 직접 연동하는 대신, 사용자가 외부 AI 도구를 활용하고 생성 결과를 앱에 등록하는 방식을 사용합니다.

### 3. 테스트 실행 및 결과 기록
- 테스트 케이스별 실행 기록 관리
- 테스트 결과 구분
  - `Not Run`: 미실행
  - `PASS`: 통과
  - `FAIL`: 실패
  - `BLOCKED`: 실행 불가
- 게임 버전 및 빌드 버전 기록
- Windows 실행 환경과 해상도 기록
- 실제 결과 및 추가 메모 저장
- 동일한 테스트 케이스의 반복 실행 이력 관리

테스트는 사용자가 직접 실행하며, 앱은 결과를 기록하고 관리하는 역할을 수행합니다.

### 4. 버그 리포트 관리
- 실패한 테스트 실행 기록을 바탕으로 버그 리포트 작성
- 재현 절차 및 기대 결과·실제 결과 기록
- 관련 이슈 및 테스트 케이스 연결
- 심각도, 우선순위 및 처리 상태 관리
- Markdown 형식으로 리포트 활용

### 5. 수정 요청 메일 초안 작성
- 버그 리포트를 기반으로 업무용 메일 초안 생성
- 제목과 본문 편집
- 메일 제목 및 본문 복사
- 수정 요청 내용을 검토한 뒤 외부 메일 서비스에서 활용

메일 자동 발송 기능은 제공하지 않습니다.

### 6. 데이터 내보내기 및 백업
- Markdown 형식으로 QA 데이터 내보내기
- CSV 형식으로 이슈, 테스트 케이스, 실행 이력 및 버그 리포트 내보내기
- JSON 형식의 데이터 백업 및 복원
- 로컬 데이터의 지속적인 관리

### 7. 데이터 검증 및 오류 처리
- 잘못된 Markdown 및 JSON 입력 검증
- 필수 항목 누락 및 잘못된 참조에 대한 안내
- 중복 데이터 확인
- 데이터 저장 및 복원 시 오류 처리
- 주요 사용자 작업 흐름의 통합 검증

## 기술 및 구현 방향

- **Application:** HTML, CSS, JavaScript 기반 웹 애플리케이션
- **Data Storage:** 브라우저 로컬 저장소 기반 데이터 관리
- **AI Integration:** 외부 AI 도구를 활용한 수동 프롬프트 및 결과 등록 방식
- **Target Platform:** Windows 게임 빌드 QA
- **Development Approach:** AI 보조 개발(Vibe Coding)을 활용한 단계별 기능 구현

별도의 백엔드 서버나 데이터베이스를 구축하지 않고, 브라우저에서 데이터를 관리하는 MVP를 목표로 구현했습니다.

## 사용 방법

### 1. 프로젝트 실행
프로젝트 파일을 내려받거나 Git으로 복제한 뒤, 프로젝트에 포함된 시작 HTML 파일(`index.html` 또는 단독 실행 파일인 [`UnityQACompanion-standalone.html`](./UnityQACompanion-standalone.html))을 브라우저에서 실행합니다.
- 다운로드 없이 바로 확인하려면 [**Unity QA Companion 웹 미리보기 (Vercel)**](https://unity-qa-companion.vercel.app/) 링크로 즉시 접속할 수 있습니다.

### 2. 프로젝트 생성 및 이슈 가져오기
프로젝트 정보를 등록하고 기존 `Issues.md` 파일을 업로드합니다. 파싱된 이슈 목록과 원문을 비교해 결과를 검수합니다.

### 3. 테스트 케이스 작성
테스트 대상 이슈를 선택해 AI 프롬프트를 생성합니다. 프롬프트를 외부 AI 도구에 입력한 뒤 생성된 결과를 앱에 붙여넣고 검수하여 테스트 케이스로 등록합니다.

### 4. 테스트 실행 및 기록
Windows 게임 빌드에서 테스트 케이스를 직접 실행한 후 결과를 기록합니다. 실행 환경, 실제 결과, 메모를 함께 관리할 수 있습니다.

### 5. 버그 리포트 및 수정 요청 작성
실패한 테스트 결과를 바탕으로 버그 리포트를 작성하고, 필요한 경우 수정 요청 메일 초안을 생성합니다.

### 6. 결과 내보내기 및 백업
작성한 QA 데이터를 Markdown 또는 CSV로 내보내거나 JSON 백업 파일로 보관합니다.

## 데이터 저장 관련 안내

- 데이터는 브라우저의 로컬 저장소에 보관됩니다.
- 브라우저 데이터 삭제, 저장 공간 제한 또는 브라우저 환경 변경으로 데이터에 접근할 수 없게 될 수 있습니다.
- 중요한 데이터는 JSON 백업 기능을 활용해 별도로 보관하는 것을 권장합니다.
- 외부 AI 도구에 이슈 내용을 입력할 때는 프로젝트의 보안 정책과 공유 가능한 정보인지 확인해야 합니다.

## 현재 구현 범위 및 제한 사항

- 실제 게임 빌드 실행 및 입력 자동화는 구현 범위에 포함하지 않습니다.
- 테스트 실행과 결과 기록은 사용자가 직접 수행합니다.
- AI API 직접 연동 및 자동 메일 발송은 제공하지 않습니다.
- Windows 게임 빌드 QA를 주요 대상으로 합니다.
- 서버 기반 협업 및 중앙 데이터 관리는 제공하지 않습니다.
